# Original T4.0 graphic packs

Unchanged copies of the graphic packs from the *Travian-T4 (SHADOW) PHP 8* edition:

| Folder | Pack |
|---|---|
| `travian_Travian_4.0_41/` | Travian 4.0 classic |
| `travian_basic/` | Travian basic |

Their CSS targets the old T4.0 HTML and does not work with the T4.4 pages. The game uses the skins
in `../compat/` (`t40.css`, `basic.css`), which re-skin the T4.4 layout with graphics taken from these packs
(copied, and mirrored for left-to-right where needed, into `../compat/t40/` and `../compat/basic/`).

These folders are kept as the source for further skin work and are **not** bundled into the iOS app.
