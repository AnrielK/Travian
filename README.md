## Instalace (XAMPP / Windows i Linux)

1. Vytvoř v MySQL/MariaDB prázdnou databázi (např. `travian`, phpMyAdmin → Databáze).
2. Otevři `http://localhost/<složka>/setup/` a vyplň přístup k databázi a nastavení serveru.
   Instalátor uloží přístup do `application/db_local.php` (soubor `config.php` se už nepřepisuje)
   a před vytvořením tabulek smaže všechny tabulky hry, takže ho jde bez problémů spustit znovu.
   Když se něco nepovede, zobrazí chybu SQL a dál nepokračuje.
3. Po dokončení se instalátor zamkne (`setup/install.lock`); pro novou instalaci smaž tento soubor.
